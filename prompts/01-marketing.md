### 1. Calendario de contenidos mensual
~~~
Actúa como community manager de una pyme del sector [sector] en [ciudad]. Crea un calendario de publicaciones para [mes] en [Instagram / LinkedIn / Facebook], con 3 publicaciones por semana. Para cada una indica: fecha, objetivo (atraer, educar o vender), idea del post, formato (carrusel, reel, imagen) y llamada a la acción. Mi cliente ideal es [descripción].
~~~

### 2. Post para LinkedIn a partir de un caso real
~~~
Escribe un post de LinkedIn de máximo 1.200 caracteres contando este caso: [qué problema tenía el cliente, qué hicimos, qué resultado obtuvo]. Empieza con una frase que enganche, usa párrafos cortos, tono profesional y cercano, y termina con una pregunta para generar comentarios. Sin emojis excesivos.
~~~

### 3. Newsletter mensual
~~~
Redacta una newsletter para los clientes de [nombre del negocio], que se dedica a [actividad]. Incluye: asunto atractivo (3 opciones), saludo breve, una novedad del mes [novedad], un consejo útil sobre [tema] y una llamada a la acción para [objetivo]. Máximo 300 palabras.
~~~

### 4. Textos para la web
~~~
Escribe el texto de la página de inicio de [nombre del negocio]. Ofrecemos [servicios] a [público objetivo] en [zona]. Nos diferencia [diferencial]. Incluye: titular principal, subtítulo, 3 beneficios con una frase cada uno, una sección "por qué elegirnos" y un botón de llamada a la acción. Optimiza para la búsqueda "[palabra clave]".
~~~

### 5. Ideas para reutilizar un contenido
~~~
Tengo este contenido: [pega el texto o resumen]. Dame 8 formas de reutilizarlo en distintos canales (Instagram, LinkedIn, newsletter, Google Business Profile, WhatsApp) e indica para cada una el formato y el texto propuesto.
~~~
